# No currency conversion; Vendor is per registrable-domain

Items are scraped from vendors across countries (e.g. `amazon.com` in USD, `amazon.com.br` in BRL). We store each Item's price in its native scraped Currency and never convert or normalize across currencies — Coupon Rules must explicitly declare the Currency their price threshold applies in, and only ever compare same-currency. Correspondingly, Vendor is derived per registrable domain rather than merged by brand, since `amazon.com` and `amazon.com.br` are different Currencies (and different fulfillment realities) even though they're the "same" retailer. This avoids building exchange-rate handling (staleness, accuracy, which rate source) before there's a real need for cross-currency comparison; revisit if users ask to compare/aggregate prices across currencies.
